The Mallow Jellybean Machine enables randomly drawn drops of pre-minted MPL Core NFTs and limited edition collections. It extends the gumball model with **edition-based rarity**: each item's draw probability is proportional to its remaining supply, so low-supply editions are naturally rarer and harder to win than high-supply ones.

## How Rarity Works

A jellybean machine can hold up to 255 distinct items. Each item is either:

- **Metaplex Core 1/1 asset** — a single pre-minted Core asset.
- **Metaplex Core limited edition** — an MPL Core master edition with a fixed `max_supply`. Each draw mints a new numbered print from this collection, up to the cap.

When a draw occurs, the program randomly selects an item weighted by its **remaining unredeemed supply**. This means:

- An edition with 100 remaining prints is 10× more likely to be drawn than one with 10 remaining prints.
- As popular editions run out, rarer ones with smaller initial supplies become an increasing fraction of the pool.
- The final draw automatically closes the sale.

This creates a natural rarity system without any off-chain coordination — rarity is determined entirely by supply, enforced on-chain.

## Account: `JellybeanMachine`

The jellybean machine account stores configuration and tracks state. Item data is stored in a hidden section appended after the base account data and grows dynamically as items are added.

| Field | Type | Description |
|---|---|---|
| `version` | `u8` | Account version (currently `0`) |
| `authority` | `Pubkey` | Authority that controls settings and item management |
| `mint_authority` | `Pubkey` | Authority that is allowed to call `draw` |
| `fee_accounts` | `Vec<FeeAccount>` | Fee recipients for draw proceeds (max 6, must sum to 10000 bps) |
| `print_fee_config` | `Option<PrintFeeConfig>` | Optional additional fee charged per edition print |
| `items_loaded` | `u8` | Number of distinct items currently loaded (max 255) |
| `supply_loaded` | `u64` | Total supply across all items |
| `supply_redeemed` | `u64` | Total number of draws that have occurred |
| `state` | `JellybeanState` | Current machine state |
| `uri` | `String` | Off-chain metadata URI (max 196 characters) |
| `padding` | `[u8; 320]` | Reserved space for future fields |

### `LoadedItem` (hidden per-item section)

Each item appended to the machine account has the following layout:

| Field | Type | Description |
|---|---|---|
| `mint` | `Pubkey` | Asset address (Core asset for one-of-ones, collection for editions) |
| `supply_loaded` | `u32` | Total supply when the item was added |
| `supply_redeemed` | `u32` | Number of draws that selected this item |
| `supply_claimed` | `u32` | Number of draws that have been claimed/settled |
| `escrow_amount` | `u64` | SOL held to cover printing fees (editions only; 0 for one-of-ones) |

### `FeeAccount`

| Field | Type | Description |
|---|---|---|
| `address` | `Pubkey` | Wallet that receives this share of each draw's payment |
| `basis_points` | `u16` | Share of proceeds in basis points (100 = 1%) |

All fee accounts must sum to exactly `10000` basis points. An empty `fee_accounts` vec is also valid (no fee distribution).

### `PrintFeeConfig`

An optional extra fee paid to a designated address each time an edition print is created. This is charged in addition to the draw payment.

| Field | Type | Description |
|---|---|---|
| `address` | `Pubkey` | Recipient of the print fee |
| `amount` | `u64` | Fee in lamports per edition print |

## Account: `UnclaimedPrizes`

A per-buyer PDA that tracks draws that have been won but not yet claimed. Seeded by `["unclaimed_prizes", jellybean_machine, buyer]`.

| Field | Type | Description |
|---|---|---|
| `version` | `u8` | Account version |
| `jellybean_machine` | `Pubkey` | The machine this account belongs to |
| `buyer` | `Pubkey` | The buyer who won these prizes |
| `prizes` | `Vec<Prize>` | List of unclaimed draws |

### `Prize`

| Field | Type | Description |
|---|---|---|
| `item_index` | `u8` | Index of the drawn item in the machine (0-based) |
| `edition_number` | `u32` | Edition number assigned to this draw (1-based for both prints and one-of-ones) |

The account is dynamically resized as prizes are added and removed. It is closed and its rent returned to the buyer (or payer if the buyer account is closed) once all prizes are claimed.

## `JellybeanState`

| State | Value | Description |
|---|---|---|
| `None` | `0` | Initial state. Items can be added and removed. Settings can be updated. |
| `SaleLive` | `1` | Sale is active. Draws are allowed. Items can no longer be added. Settings (URI, fee recipients, print fee config) can still be updated, but the number of fee accounts cannot change. |
| `SaleEnded` | `2` | Sale has ended. No further draws. Unsold items can be removed. Buyers can still claim. |

## Jellybean Machine Lifetime

```
                        ┌─────────────────────────────────┐
                        │           SETUP PHASE           │
                        │                                 │
                        │  initialize                     │
                        │     │                           │
                        │     ▼                           │
                        │  [state: None]                  │
                        │     │                           │
                        │     ├── add_core_item (×N)      │
                        │     ├── remove_core_item        │
                        │     └── update_settings         │
                        └──────────────┬──────────────────┘
                                       │ start_sale
                                       ▼
                        ┌─────────────────────────────────┐
                        │            SALE PHASE           │
                        │                                 │
                        │  [state: SaleLive]              │
                        │     │                           │
                        │     ├── draw (×N)               │
                        │     │   (last draw auto-ends    │
                        │     │    the sale)              │
                        │     ├── claim_core_item (×N)    │
                        │     └── update_settings         │
                        │         (uri/fees only; count   │
                        │          cannot change)         │
                        └──────────────┬──────────────────┘
                                       │ end_sale (or auto)
                                       ▼
                        ┌─────────────────────────────────┐
                        │         SETTLEMENT PHASE        │
                        │                                 │
                        │  [state: SaleEnded]             │
                        │     │                           │
                        │     ├── claim_core_item (×N)    │
                        │     ├── remove_core_item        │
                        │     │   (unsold items only)     │
                        │     └── withdraw                │
                        │         (requires items_loaded  │
                        │          == 0)                  │
                        └─────────────────────────────────┘
```

`set_mint_authority` can be called at any point before `withdraw`.

## Instructions

### `initialize`

Initializes a new jellybean machine. The account must be pre-allocated by the payer before calling this instruction (use `createJellybeanMachine` from the UMI client, which handles allocation automatically).

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | Pre-allocated machine account (must be zero-initialized) |
| 1 | `authority` | | | Authority that will control this machine |
| 2 | `authority_pda` | ✓ | | PDA (seeds: `["jellybean_machine", jellybean_machine]`) |
| 3 | `payer` | ✓ | ✓ | Pays for the authority PDA |
| 4 | `system_program` | | | |

**Arguments:** `SettingsArgs`

| Argument | Type | Description |
|---|---|---|
| `uri` | `String` | Off-chain metadata URI for the machine (max 196 chars) |
| `fee_accounts` | `Vec<FeeAccount>` | Fee distribution (max 6 accounts, must sum to 10000 bps) |
| `print_fee_config` | `Option<PrintFeeConfig>` | Optional per-print fee |

---

### `update_settings`

Updates the machine's URI, fee accounts, and print fee config. Can only be called in the `None` or `SaleLive` state (not after the sale has ended). The number of fee accounts cannot change after initialization.

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | |
| 1 | `authority` | ✓ | ✓ | Must match `jellybean_machine.authority` |

**Arguments:** `SettingsArgs` (same as `initialize`)

---

### `add_core_item`

Adds an item to the machine. Must be in the `None` state. Supports two item types:

**One-of-one Core asset** — pass the asset account. The asset is transferred into the authority PDA's custody.

**Limited edition collection** — pass the collection account (must have the `MasterEdition` plugin with a defined `max_supply` and zero existing prints). The collection's update authority is transferred to the authority PDA. SOL equal to the estimated printing cost (rent + 1.5M lamport Metaplex fee) is escrowed per edition slot.

The machine account is reallocated to accommodate the new `LoadedItem` entry.

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | Must be in `None` state |
| 1 | `authority_pda` | ✓ | | PDA (seeds: `["jellybean_machine", jellybean_machine]`) |
| 2 | `authority` | ✓ | ✓ | |
| 3 | `payer` | ✓ | ✓ | Pays for account reallocation and edition escrow |
| 4 | `asset` | ✓ | | (Optional) Core asset account for one-of-ones |
| 5 | `collection` | ✓ | | (Optional) Master edition collection for limited editions |
| 6 | `mpl_core_program` | | | |
| 7 | `system_program` | | | |

Exactly one of `asset` or `collection` must be provided.

---

### `remove_core_item`

Removes an item from the machine by index. Can be called in `None` state (before the sale) or `SaleEnded` state (to reclaim unsold items). The item must be fully claimed before removal (i.e. `supply_redeemed == supply_claimed`).

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | Must be in `None` or `SaleEnded` state |
| 1 | `authority_pda` | ✓ | | PDA (seeds: `["jellybean_machine", jellybean_machine]`) |
| 2 | `authority` | ✓ | ✓ | |
| 3 | `asset` | ✓ | | (Optional) Core asset account |
| 4 | `collection` | ✓ | | (Optional) Master edition collection |
| 5 | `mpl_core_program` | | | |
| 6 | `system_program` | | | |

**Arguments:**

| Argument | Type | Description |
|---|---|---|
| `index` | `u8` | Zero-based index of the item to remove |

---

### `start_sale`

Transitions the machine from `None` to `SaleLive`, enabling draws. Requires at least one item to be loaded.

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | Must be in `None` state with `items_loaded > 0` |
| 1 | `authority` | | ✓ | Can be `authority` or `mint_authority` |

---

### `end_sale`

Transitions the machine to `SaleEnded`, disabling further draws. Can be called from either `None` or `SaleLive` state. Also called automatically when the last item is drawn.

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | Must not already be in `SaleEnded` state |
| 1 | `authority` | ✓ | ✓ | |

---

### `draw`

Performs a random draw, selecting an item for a buyer. Only callable by the `mint_authority`. Requires the machine to be in `SaleLive` state.

The selection is weighted by each item's remaining unredeemed supply — items with more supply remaining are proportionally more likely to be selected. Randomness is seeded from the most recent slot hash combined with the current unix timestamp.

The draw result is stored in the buyer's `UnclaimedPrizes` account (created if it doesn't exist). For edition draws, the escrow for that print's creation cost is transferred from the payer to the authority PDA. If the draw exhausts all supply, the machine transitions to `SaleEnded`.

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | Must be in `SaleLive` state |
| 1 | `authority_pda` | ✓ | | PDA (seeds: `["jellybean_machine", jellybean_machine]`) |
| 2 | `mint_authority` | | ✓ | |
| 3 | `payer` | ✓ | ✓ | Pays for `UnclaimedPrizes` creation and edition escrow |
| 4 | `buyer` | | | Recipient of the draw |
| 5 | `unclaimed_prizes` | ✓ | | PDA (seeds: `["unclaimed_prizes", jellybean_machine, buyer]`) |
| 6 | `print_fee_account` | ✓ | | (Optional) Required if `print_fee_config` is set |
| 7 | `system_program` | | | |
| 8 | `rent` | | | |
| 9 | `recent_slothashes` | | | SlotHashes sysvar |
| 10 | `event_authority` | | | PDA for event emission |
| 11 | `program` | | | Self-reference for CPI event |

**Events emitted:** `DrawItemEvent { authority: Pubkey, index: u32, edition_number: u32 }`

---

### `claim_core_item`

Claims a drawn prize, delivering the asset to the buyer. This instruction is **permissionless** — anyone can pay for and submit it on behalf of any buyer. The machine must be in `SaleLive` or `SaleEnded` state.

**For one-of-one assets:** the Core asset is transferred from the authority PDA directly to the buyer.

**For limited editions:** a new numbered print is created using `CreateV1` with an `Edition` plugin. The escrowed SOL (held in the authority PDA) is returned to the payer to cover the creation cost.

The `UnclaimedPrizes` account is reallocated after each claim. When all prizes for a buyer are claimed, the account is closed and its rent returned to the buyer (or payer if the buyer account is closed).

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `payer` | ✓ | ✓ | Pays transaction and print creation fees |
| 1 | `jellybean_machine` | ✓ | | Must be in `SaleLive` or `SaleEnded` state |
| 2 | `authority_pda` | ✓ | | PDA (seeds: `["jellybean_machine", jellybean_machine]`) |
| 3 | `buyer` | ✓ | | Recipient of the asset |
| 4 | `unclaimed_prizes` | ✓ | | PDA (seeds: `["unclaimed_prizes", jellybean_machine, buyer]`) |
| 5 | `asset` | ✓ | | (Optional) Core asset for one-of-ones |
| 6 | `collection` | ✓ | | (Optional) Master edition collection for prints |
| 7 | `print_asset` | ✓ | ✓ | (Optional) New keypair for the edition print |
| 8 | `mpl_core_program` | | | |
| 9 | `system_program` | | | |
| 10 | `event_authority` | | | PDA for event emission |
| 11 | `program` | | | Self-reference for CPI event |

**Arguments:**

| Argument | Type | Description |
|---|---|---|
| `index` | `u8` | Zero-based index of the item to claim |

**Events emitted:** `ClaimItemEvent { authority: Pubkey, edition_number: u32 }`

---

### `set_mint_authority`

Replaces the `mint_authority` of the machine. Both the current `authority` and the new `mint_authority` must sign.

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | |
| 1 | `authority` | | ✓ | Current `authority` |
| 2 | `mint_authority` | | ✓ | New `mint_authority` (signs to accept) |

---

### `withdraw`

Closes the jellybean machine account, returning all rent lamports to the authority. Both `authority` and `mint_authority` must sign. Requires `items_loaded == 0` — all items must have been removed first.

**Accounts:**

| # | Name | Writable | Signer | Description |
|---|---|---|---|---|
| 0 | `jellybean_machine` | ✓ | | Will be closed; requires `items_loaded == 0` |
| 1 | `authority` | ✓ | ✓ | Receives rent lamports |
| 2 | `mint_authority` | ✓ | ✓ | |
